踩坑：z-ai 并行搜索限流

8个 z-ai function -n web_search 同时并行会触发 429 Too Many Requests。安全并发数约2-3个，超过需分批串行执行。每次搜索间隔几秒即可避免限流。

踩坑：web_search 长中文查询会 422（2026-08-08 实战）

z-ai function -n web_search 对长中文查询（≥10字、多关键词以空格分隔）会返回：

422 | "No search results available for query ..."

无论换多少种长中文组合都不行（"快递三轮车国标GB7258机动车分类" "电动三轮车法规" 全部422）。

正确解法：

  1. 改用英文查询（如 electric tricycle China regulation standard）—— 100%可用
  2. 或极简中文（2-4字组合，如 电动三轮车 上牌 驾照 D证，但仍可能422）
  3. 英文搜索结果通常带中文网站的英文介绍，可获取关键标准编号、关键词
  4. 再用这些关键词做第二轮中文精准搜索（如 GB7258 电动三轮摩托车 D证）—— 这次可用

结论：web_search 中文长查询命中率低，先用英文打捞关键词，再用短中文精准搜。

踩坑：page_reader 函数名（2026-08-08 实战）

  • ❌ web_reader 不存在（400 Unknown function）
  • ✅ 正确函数名：page_reader
  • 调用：z-ai function -n page_reader -a '{"url":"..."}' -o out.json
  • 返回字段：title / html / text / publish_time / url / metadata

限制：政府官网（如 bjfsh.gov.cn）有JS验证码/脚本遮挡，page_reader 抓不到正文，只能拿到导航和脚本片段。但 web_search 结果的 snippet 摘要通常已包含核心信息（如"驾驶电动三轮车需取得D证"），可作主要信息源，page_reader 仅作补充。

MACD手动计算（akshare不可用时的替代）

def ema(values, period):
    k = 2 / (period + 1)
    e = values[0]
    result = [e]
    for v in values[1:]:
        e = v * k + e * (1 - k)
        result.append(e)
    return result

ema12 = ema(closes, 12)
ema26 = ema(closes, 26)
dif = [ema12[i] - ema26[i] for i in range(len(closes))]
dea = ema(dif, 9)
macd = [(dif[i] - dea[i]) * 2 for i in range(len(closes))]

投资理论体系知识库（2026-06-04 学习整理）

一、缠论（缠中说禅技术分析理论）

  • 创始人：缠中说禅（网名），2006-2008年新浪博客发表
  • 核心哲学：走势终完美 —— 任何级别的任何走势（趋势或盘整），最终都要完成
  • 递进结构：分型 → 笔 → 线段 → 中枢 → 走势类型
    • 分型：顶分型（中间K线最高）和底分型（中间K线最低），最小结构单元
    • 笔：相邻顶底分型之间连线，至少5根K线
    • 线段：至少3笔构成，线段破坏需出现反向线段
    • 中枢：至少3个有重叠部分的连续线段构成，缠论核心概念
    • 走势类型：趋势（2个以上同级别中枢）和盘整（仅1个中枢）
  • 三类买卖点：
    • 一买/一卖：背驰点，趋势力度衰竭的转折点（最安全但最难判断）
    • 二买/二卖：次级别回踩不破前低/前高（确认反转）
    • 三买/三卖：中枢破坏点，次级别离开中枢后回拉不进中枢（趋势延续确认）
  • 关键辅助：背驰判断（MACD面积/黄白线）、均线趋势力度、量价关系

二、波浪理论（艾略特波浪理论 Elliott Wave）

  • 创始人：R.N. Elliott，1930年代提出
  • 核心模式：八浪循环 —— 5个推动浪（1-2-3-4-5）+ 3个调整浪（A-B-C）
  • 三大铁律：
    1. 浪2回撤不超过浪1起点
    2. 浪3不是最短的推动浪（通常最长）
    3. 浪4不进入浪1的价格区域
  • 推动浪特征：浪1起步→浪2回调→浪3主升（最强，常延伸）→浪4复杂调整→浪5最后冲刺（量能常背离）
  • 调整浪分类：
    • 锯齿形（5-3-5）：陡直快速，A跌B弹C再跌
    • 平台形（3-3-5）：横向整理，幅度较浅
    • 三角形（3-3-3-3-3）：收敛整理，出现在浪4或B浪
    • 复合形：双重三、三重三等
  • 核心原则：市场按可识别模式循环运行，大浪套小浪，分形结构

三、江恩理论（Gann Theory）

  • 创始人：威廉·D·江恩（W.D. Gann），20世纪初
  • 核心思想：价格、时间和空间之间存在数学和几何关系
  • 三大核心工具：
    • 江恩角度线（Gann Fan）：1×1线（45°）为趋势分水岭，站上多头、跌破空头
    • 江恩九方图（Square of Nine）：螺旋排列，0°/45°/90°/180°上的数字互为价格目标
    • 江恩轮中轮：圆形分割整合不同周期循环，24等分对应时间周期
  • 江恩核心法则：
    • 时间与价格的平衡是市场转折关键
    • 历史以数学比例方式重演
    • 重要时间周期：30天、90天、180天、360天
    • 价格回撤关键比例：1/8、1/4、1/3、3/8、1/2、5/8、2/3、3/4、7/8

四、道氏理论（Dow Theory）

  • 创始人：查尔斯·道（Charles Dow），技术分析之祖
  • 六大基本原则：
    1. 价格反映一切（所有已知信息已体现在价格中）
    2. 趋势分三个层级：主要趋势（数月至数年）、次级趋势（数周至数月，回撤1/3至2/3）、日间波动（数天，无分析价值）
    3. 主要趋势三阶段：积累期（聪明资金进场）→参与期（大众跟进）→派发期（聪明资金离场）
    4. 指数需互相印证（两个相关指数同向确认才有效）
    5. 成交量须配合趋势方向（上涨放量、下跌缩量为健康）
    6. 趋势持续直到出现明确反转信号

五、基本面分析

  • 核心逻辑：价格围绕内在价值波动，长期回归价值
  • 分析维度：宏观经济（GDP/CPI/利率/汇率/政策）→ 行业分析（生命周期/竞争格局/政策）→ 公司分析（财务报表/估值）
  • 关键指标：
    • 盈利能力：ROE、毛利率、净利率
    • 成长性：营收增速、利润增速
    • 安全性：资产负债率、流动比率、现金流
    • 估值方法：PE、PB、PS、DCF、PEG、EV/EBITDA

六、技术面分析

  • 核心假设：价格反映一切、价格沿趋势运动、历史会重演
  • 分析工具：
    • K线形态：头肩顶/底、双顶/底、三角形、旗形、楔形
    • 趋势指标：MA、EMA、BOLL、MACD
    • 动量指标：RSI、KDJ、WR、CCI
    • 量能指标：OBV、VWAP、成交量
    • 支撑阻力：前高前低、整数关口、黄金分割位
  • 核心原则：顺势而为、量价配合验证、多周期共振、指标背离预警

七、资金面分析

  • 核心逻辑：资金是推动股价的直接动力，跟踪"聪明钱"
  • 分析维度：
    • 主力资金：特大单/大单流入流出，判断机构动向
    • 北向资金：外资动向，A股风向标
    • 筹码分析：集中度、获利比例、套牢盘分布
    • 量价关系：量增价升（健康）、量缩价涨（虚涨）、量增价跌（出货）
    • 龙虎榜：游资/机构席位，短线情绪指标
    • 融资融券：杠杆资金变化，市场情绪温度计
  • 量价口诀：量增价升→买入 | 量增价平→转势 | 量增价跌→卖出 | 量缩价升→警惕 | 量缩价跌→观望 | 地量地价→可能见底

价值投资与绩优股分析体系（2026-06-05 学习整理）

一、格雷厄姆——价值投资之父

  • 代表著作：《证券分析》(1934)、《聪明的投资者》(1949)
  • 三大核心原则：
    1. 安全边际：买入价格必须远低于内在价值（通常30%-50%折扣），抵御分析误差、市场波动和黑天鹅
    2. 市场先生：市场是情绪化的"先生"，每天报价给你——你可以利用他的情绪，但不要被他左右
    3. 内在价值：股票背后是企业，价格围绕内在价值波动，长期终将回归
  • 选股标准（十条）：股价低于净有形资产2/3、低PE、低负债、连续分红、10年盈利增长、股价不高于净资产1.5倍等
  • 投资风格：定量为主，寻找"烟蒂股"（被严重低估的股票），分散投资
  • 历史地位：价值投资理论奠基人，巴菲特的导师

二、费雪——成长股投资之父

  • 代表著作：《怎样选择成长股》(1958)
  • 核心方法：闲聊法 —— 通过供应商、客户、竞争对手、前员工等多方调研，验证公司真实质量
  • 选股十五要点（核心摘要）：
    1. 产品是否有足够市场潜力使销售额大幅增长？
    2. 管理层是否有决心继续开发新产品/新工艺？
    3. 研发投入相对规模如何？
    4. 是否有高于平均的销售组织？
    5. 是否有高利润率？
    6. 为维持/改善利润率做了什么？
    7. 劳资关系是否良好？
    8. 高层关系是否融洽？
    9. 管理层是否有足够深度？
    10. 成本分析和会计控制如何？
    11. 行业中是否有独特竞争优势（护城河）？
    12. 是否有长期/短期利润视角？
    13. 是否需要稀释股权融资？
    14. 管理层是否坦诚面对困难？
    15. 管理层是否诚信？
  • 投资风格：定性为主，集中持有少数杰出公司（通常3-5只），长期持有数十年
  • 核心信条：找到真正杰出的公司，抱牢度过波动，远比频繁买卖赚得多

三、巴菲特——价值投资的集大成者

  • 核心哲学：85%格雷厄姆 + 15%费雪（后期受芒格影响，更偏向费雪）
  • 四大支柱：
    1. 安全边际：以折扣价买入优质企业，为判断失误留余地
    2. 能力圈：只投资自己能理解的企业，不懂不碰——"知道能力圈的边界比圈有多大更重要"
    3. 护城河：企业必须拥有持久竞争优势（品牌、网络效应、转换成本、成本优势、许可/专利）
    4. 长期持有："如果你不愿意持有一只股票10年，就不要持有10分钟"
  • 选股标准：业务简单易懂、持续稳定的盈利历史、高ROE（长期>15%）、低负债、高利润率、自由现金流充沛、优秀的管理层、合理或低估的价格
  • 经典案例：可口可乐（品牌护城河）、GEICO（低成本优势）、苹果（生态锁定）、美国运通（品牌+网络效应）
  • 核心金句：
    • "别人贪婪我恐惧，别人恐惧我贪婪"
    • "价格是你付出的，价值是你得到的"
    • "以合理价格买入优秀企业，远胜以便宜价格买入平庸企业"

四、芒格——巴菲特的黄金搭档

  • 代表著作：《穷查理宝典》
  • 核心哲学：多元思维模型 —— 掌握80-90个来自不同学科的重要模型，形成"普世智慧"
  • 关键思维模型：
    • 逆向思考："反过来想，总是反过来想"——先想怎样会失败，然后避免它
    • 能力圈：清楚自己不知道什么，比知道自己知道什么更重要
    • 检查清单：投资决策前逐项核查，避免认知偏差
    • lollapalooza效应：多种因素同向叠加产生极端结果（好或坏）
  • 对巴菲特的影响：推动巴菲特从"烟蒂股"转向"以合理价格买入伟大企业"
  • 投资标准：用"伟大企业"替代"便宜价格"——宁可以合理价格买伟大公司，不以便宜价格买平庸公司
  • 核心金句："我这一生只想知道我会死在哪里，这样我就永远不会去那个地方"

五、彼得·林奇——成长型价值投资

  • 管理麦哲伦基金13年，年化29%
  • 六种公司分类：
    1. 缓慢增长型：大型成熟企业，增速≈GDP，分红为主（电力、银行）
    2. 稳定增长型：大白马，年增10%-12%，熊市防御（可口可乐、宝洁）
    3. 快速增长型：小而快，年增20%-30%，林奇最爱，十倍股摇篮
    4. 周期型：业绩随经济周期大起大落（汽车、钢铁、化工）
    5. 困境反转型：破产边缘但可能浴火重生，高风险高回报
    6. 隐蔽资产型：资产价值被市场忽视（土地、专利、子公司）
  • 选股法则：PEG<1、公司内部人买入、机构持股比例低、用常识投资、不追热门
  • 25条黄金法则核心：做功课、买你懂的、忽略短期波动、持有好公司
